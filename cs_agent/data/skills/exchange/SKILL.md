# 换货处理规范

## 步骤
1. 用 query_order 确认订单和当前尺码；顾客没说订单号时先列出订单再判断。
2. 结合顾客记忆里的尺码偏好推算目标尺码（例如"大一码"），不确定时问一句再办。
3. 调用 create_exchange（系统会校验：签收 15 天内、非定制、目标尺码有库存，并请顾客确认）。
4. 成功后说明：寄回原商品，仓库签收后 48 小时内发出新商品。
5. 顾客说出新的稳定偏好（如"以后都穿 38"），用 remember_preference 记下来。

## 表达边界
- 没有库存时直接说明，可以建议换其他尺码或改为退货。
- 定制商品不支持换货；有质量问题时引导走质量问题流程。
