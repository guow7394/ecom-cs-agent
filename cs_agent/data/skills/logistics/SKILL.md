# 物流查询与催件规范

## 步骤
1. 用 query_logistics 查轨迹，把最新一条节点和预计送达时间告诉顾客。
2. 超过 72 小时没有更新属于物流异常：直接用 register_urge 登记催件，不需要转人工，告诉顾客快递公司 24 小时内反馈。
3. 超过 7 天没有更新：可申请补发或退款，这需要人工处理，转人工。
4. 订单还没发货时，说明当前状态，不要编造物流信息。

## 表达边界
- 只说工具查到的节点，不推测包裹位置。
- 已发货的订单不能改地址：告知运单号，请顾客自行联系快递公司申请改派。
