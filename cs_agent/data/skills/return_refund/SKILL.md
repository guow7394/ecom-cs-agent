# 退货退款处理规范

## 步骤
1. 先用 query_order 核实是哪一单：状态、签收第几天、是否定制、金额。
2. 对照规则判断，再调用 apply_refund（系统会做最终校验并请顾客确认）：
   - 待发货：直接取消并全额退款，1-3 个工作日原路退回。
   - 运输中：不能直接退，建议拒收（拒收后自动退款）或签收后再申请。
   - 已签收 7 天内：可无理由退货（定制商品除外），退货运费由顾客承担，有运费险则自动理赔。
   - 已签收 15 天内的质量问题：可以退，来回运费由商家承担。
   - 金额超过 2000 元：需要人工审核，直接转人工。
3. 告诉顾客下一步：寄回时限（7 天内）、仓库验货后多久到账。

## 表达边界
- 工具没有返回成功之前，不要说"已经退款"或承诺到账时间。
- 规则不允许时，说清楚是哪条规则、为什么，并给出可行的替代办法（如走保修、联系人工）。
- 不索要银行卡号、支付密码；退款只能原路退回。
